## 2. Storage engine

- **Node 22 built-in `node:sqlite`** (`DatabaseSync`), probed on the pinned
  runtime 22.22.2. Zero npm dependencies. Experimental warning goes to stderr;
  stdout JSON contracts unaffected.
- Fallback (documented, not built): `better-sqlite3` behind the same class API.
- `PRAGMA journal_mode = WAL`; single-writer.

## 3. Schema (JSON blob + index columns)

```sql
nodes(id TEXT PK, type TEXT, state TEXT, dimension_id TEXT NULL, data TEXT)
edges(id TEXT PK, type TEXT, from_id TEXT, to_id TEXT, data TEXT)
constraints(id TEXT PK, kind TEXT, state TEXT, data TEXT)
```

`data` = full object as JSON; upsert via `INSERT OR REPLACE`. Type evolution
never requires a migration (open-world typing).

## 4. `SqliteGraph` mechanics

```ts
export class SqliteGraph extends MemoryGraph {
  constructor(path: string);   // create tables if missing; load all rows into maps
  close(): void;               // close the db (tests / CLI shutdown)
  // overridden write-through: addNode / addEdge / addConstraint /
  //   transitionNodeState / transitionConstraintState
  // inherited free: getters, queryNodes, evaluateConstraint
}
```

- **Durable write-through cache**: the whole graph is memory-resident; every
  mutation delegates to `super` (full M0/M1 enforcement: provenance, ids, state
  machines, Q01) then upserts the row.
- Lazy loading / paging for very large graphs: deferred.

## 5. CLI surface (`edgelore`, bin → `dist/src/cli.js`)

- Global: `--db <path>` (default `./edgelore.db`).
- Commands: `node add|list`, `edge add|list`,
  `constraint add|activate <id>|list`, `evaluate <id>`, `get <id>`.
- JSON flags: `--value` (JSON, string fallback), `--attributes`, `--bindings`,
  `--expression` (strict JSON).
- Errors: `{"error": "..."}` on stderr, exit 1. Results: single-line JSON on
  stdout.
- Q01 via the real path: `constraint add` → `proposed`; only
  `constraint activate <id> --approved-by human:x` flips to `active`.

## 6. Test summary (suite total: 39/39)

`test/sqlite.test.ts` — 6 cases:

- behavior parity: add/query/evaluate; fact-node state machine; Q01 gate
  (missing approver, agent approver rejected, human approver accepted)
- persistence: graph survives close+reopen (objects, activation state,
  evaluation); state transitions persist; evaluation reflects post-reopen
  writes (avg pushed 3000 → 5250 flips `satisfied` → `violated`)

Bug caught during M2: a test-side arithmetic error (9000 → avg 4500, still
≤ 5000), not an engine fault; corrected to 12000 (avg 5250).
