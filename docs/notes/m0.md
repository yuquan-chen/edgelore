# M0 — Technical Note

> Milestone: **M0** (data model frozen, shipped 2026-09-17).
> Audience: any agent or contributor that reads/writes the shared memory graph.
> Companion docs: `docs/shared-memory-m0-spec.md` (design rationale),
> `docs/conventions.md` (coding style), `schema.json` (open contract).

This note is the **post-implementation reference** for M0: the concrete types
and the mechanics that are live in the code. It is kept in sync with
`schema.json` (SCHEMA_VERSION `"m0.1"`).

## 2. Core types (the three-family vocabulary)

All objects carry mandatory **Provenance**:

```ts
interface Provenance {
  created_by: string;     // "agent:<name>:<id>" | "human:<id>"
  created_at: string;     // ISO-8601
  schema_version: string; // "m0.1"
  source_refs: string[];  // ids of introducing message/source
}
```

### 2.1 GraphNode (fact node) — `GraphNode = CoreNode | OpenNode`

```ts
interface BaseNode extends Provenance {
  id: string;            // "node:<type>:<uuid>"
  type: NamespacedType;  // open-world, namespaced string
  updated_at: string;
  scope?: Scope;         // { project_id?, phase_id? }
  state: FactNodeState;  // see §3
  attributes: Record<string, unknown>;  // extension point
  tags: string[];
}
```

Built-in core node shapes (discriminated by `type`):
`ActorNode`, `ProjectNode`, `DeliverableNode`, `MessageNode`, `SourceNode`,
`DimensionNode` (`key` required), `StatementNode` (`dimension_id` + `value`).
Any type outside `core:` becomes an `OpenNode`.

### 2.2 GraphEdge (entity relation)

```ts
interface GraphEdge extends Provenance {
  id: string;   // "edge:<uuid>"
  type: NamespacedType;
  from: string; // node id
  to: string;   // node id
  scope?: Scope;
  attributes: Record<string, unknown>;
  tags: string[];
}
```

Built-in core edge kinds: `core:said_by`, `core:about`, `core:has_source`,
`core:belongs_to`, `core:branch`, `core:supersedes`, `core:participates_in`.

### 2.3 Constraint (the honest hyperedge / N-ary rule)

```ts
interface Constraint extends Provenance {
  id: string;             // "constraint:<uuid>"
  kind: NamespacedType;   // usually "core:constraint"
  revision_id: string;    // "constraint-revision:<n>"
  name?: string;
  scope?: Scope;
  participants: string[];        // N-ary set of dimension node ids
  bindings: Record<string,string>;     // param -> dimension id
  parameter_types?: Record<string,string>;
  expression?: ExpressionNode;  // ★ evaluated in M1
  activation_state: ConstraintState;
  approved_by: string | null;   // ★ Q01 governance point
  approved_at: string | null;
  retired_at?: string | null;
  attributes: Record<string, unknown>;
  tags: string[];
}

interface ExpressionNode {       // shape reserved in M0, semantics in M1
  op: string;
  args: Array<ExpressionNode | { ref: string } | number>;
}
```

## 3. State enums (closed, narrow state + wide metadata)

```ts
type FactNodeState =
  | "tentative" | "accepted" | "conflict" | "superseded" | "rejected";

type ConstraintState =
  | "proposed" | "active" | "retired" | "deprecated";
```

Transitions are enforced by `FACT_STATE_TRANSITIONS` /
`CONSTRAINT_STATE_TRANSITIONS` in `state-machine.ts` and by
`MemoryGraph.transitionNodeState` / `transitionConstraintState`.

## 4. Identifiers & open-world typing

- Node id: `node:<type>:<uuid>` — e.g. `node:core:dimension:<uuid>`.
- Edge id: `edge:<uuid>`; Constraint id: `constraint:<uuid>`;
  revision id: `constraint-revision:<n>`.
- `type` is a **namespaced string**, not a closed enum: `core:*` is reserved
  for the core team; each agent/party uses its own scope (`codex:task`,
  `com.acme:invoice`, ...).
- Principals: `agent:<name>:<id>` or `human:<id>`. Identity *verification*
  is an opt-in auth layer (off by default in M0).

## 5. Q01 governance gate (critical)

A constraint may only reach `activation_state: "active"` if a **human**
approver is recorded:

- At creation: `approved_by` must be present, `validateCreatedBy` ok, and start
  with `human:`.
- At transition (`transitionConstraintState(id, "active")`): `opts.approved_by`
  is required and must be a `human:<id>`. Agents cannot self-activate a rule.

## 6. Public API (`MemoryGraph`)

| Method | Purpose |
|--------|---------|
| `addNode(input)` | create a fact node; enforces type + provenance + type-specific required fields |
| `getNode(id)` | fetch |
| `transitionNodeState(id, to)` | fact-node state machine |
| `addEdge(input)` | create an edge; endpoints must exist |
| `getEdge(id)` | fetch |
| `addConstraint(input)` | create a constraint; enforces Q01 if `active` |
| `getConstraint(id)` | fetch |
| `transitionConstraintState(id, to, opts?)` | constraint state machine + Q01 |
| `queryNodes(filter)` | filter by type/state/project/phase |
| `getAllNodes/Edges/Constraints()` | dump |

## 7. Validation surface (`identifiers.ts`)

`validateType`, `validateCreatedBy`, `validateId` — each returns
`{ ok: boolean; reason?: string }`. Called internally by the store; usable by
clients for pre-checks.

## 9. Open items carried into M1

- `Constraint.expression` is reserved but **not evaluated** — M1 builds the
  whitelisted AST evaluator (operators: comparison, arithmetic, aggregation
  over participants) returning `satisfied | violated | indeterminate | error`.
- Persistence adapters (SQLite default) are `planned` in `src/store/`.
- MCP server exposing the graph to agents is `planned` in `src/mcp/`.
