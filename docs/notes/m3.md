# edgelore · M3 — Memory Capture Primitive (technical note)

> Companion to `docs/shared-memory-m3-spec.md`. Written after build.

## What M3 is

M3 is **the storage layer** of the memory agent — the "hand", not the "brain".
The full memory loop is two segments:

1. **Agent Memory layer (future)**: a raw sentence → decide whether to store →
   emit a structured JSON (`CaptureContent`).
2. **Storage layer (M3)**: take that JSON + a runtime-supplied `CaptureContext`
   (provenance) → persist it correctly.

`capture()` implements only segment ②. It never decides *what* to remember or
*when* — that is the LLM/runtime layer's job (deferred).

## The contract (API between the two layers)

```ts
interface CaptureContent {   // Agent authors this — the JSON from Agent Memory
  dimensionKey: string;
  value: unknown;
  cardinality?: "single" | "multi";
  unit?: string;
}
interface CaptureContext {   // runtime reads this (who/what/source), not the Agent
  created_by: string;        // e.g. "agent:workbuddy:1", "human:charles"
  source_refs: string[];
}
```

Provenance (`created_by`, `source_refs`, `created_at`, `schema_version`) is
**never** authored by the Agent — the runtime injects it. This keeps the Agent
honest (it cannot forge "who said it") and keeps `capture` unit-testable.

## Storage mechanics

1. **Resolve dimension** by `key` (global in M3). Create with
   `cardinality = content.cardinality ?? "multi"` if missing.
2. **Dedupe**: exact `value` repeat → return existing statement, no write.
3. **Write statement** with `state = "accepted"` (default).
4. **Single-cardinality conflict**: if an `accepted` statement with a *different*
   value already exists, the newcomer is `tentative`, the dimension is set to
   `conflict`, and `result.conflict = true`. Multi-cardinality never conflicts.

## Return value

`CaptureResult { dimensionId, statementId|null, created, deduplicated, conflict }`
